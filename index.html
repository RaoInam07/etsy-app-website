Etsy Order Management & Automation

An automation application designed to help Etsy sellers manage order information and streamline customer communication.

About the Application

This application is designed to help Etsy sellers simplify order-related workflows and improve customer communication.


The application can integrate with the Etsy Open API and may automate selected order-management and customer-communication workflows based on the permissions granted by the seller.


The application is independently developed and is not operated, owned, or endorsed by Etsy, Inc.

Features

Order Management

Retrieve and organize relevant Etsy order information to support seller order-management workflows.

Customer Communication

Support automated customer communication workflows for order-related confirmations and information.

Workflow Automation

Reduce repetitive manual tasks by connecting order information with configured automation workflows.

How It Works

1. Seller Authorization The seller authorizes the application to access the Etsy data required for the selected workflow.
2. Order Information The application processes relevant order information available through the Etsy Open API.
3. Automated Workflow Order information can trigger configured automation workflows for the seller.
4. Customer Communication Where configured, the workflow can assist with order-related customer communication.

Privacy Policy

Information We Access

Depending on the functionality authorized by the seller, the application may access Etsy shop, order, transaction, shipping, and related information required to provide the configured automation.


How Information Is Used

Information accessed through the Etsy Open API is used only to provide and operate the application's configured order-management and automation functionality.


Authentication & Security

Etsy OAuth authentication is used where required. API credentials, OAuth tokens, and other sensitive authentication information must be stored securely and must not be publicly exposed.


Data Sharing

Information is not sold to third parties. Data may be processed by service providers required to operate the application's configured automation workflows.


Data Retention

Data should be retained only for as long as necessary to provide the requested functionality and meet applicable operational or legal requirements.
